# Прорыв плотины — визуализация зоны затопления

Интерактивная карта распространения волны прорыва по результатам расчёта
HEC-RAS 2D на ЦМР 2.5 м. Несколько сценариев, воспроизведение по времени,
отсчёт глубины под курсором. Работает как статический сайт — без сервера,
без тайлового бэкенда, без API-ключей.

Сценарий максимального паводка:
- гидрограф с макс расходом 10800 м3/с для Верхне-Тобольского водохранилища и 8850 м3/с для Каратомарского водохранилища
- затворы управляются по уровню НПУ
Сценарий прорыва плотины настроен по ширине водосбороса, а время по 10 мин на каждый затвор и снижение по УМО.

## Импорт тайлового кэша RAS Mapper
Сами `.db` кладите в `data/tilecache/` — каталог `data/` целиком в
`.gitignore`, в репозиторий уходят только собранные ассеты. Импортёр
запускается по одному разу на файл; `--name` задаёт порядок в списке,
`--label` — подпись в интерфейсе (пишется в `label.txt` рядом с растрами).
```bash
python scripts/import_rasmapper_tiles.py data/tilecache/vt_pavodok.db \
    --name 01_vt-pavodok --group "Верхне-Тобольское" --label "Максимальный паводок"
python scripts/import_rasmapper_tiles.py data/tilecache/vt_proryv.db \
    --name 02_vt-proryv  --group "Верхне-Тобольское" --label "Прорыв плотины"
python scripts/import_rasmapper_tiles.py data/tilecache/kt_pavodok.db \
    --name 03_kt-pavodok --group "Каратомарское"     --label "Максимальный паводок"
python scripts/import_rasmapper_tiles.py data/tilecache/kt_proryv.db \
    --name 04_kt-proryv  --group "Каратомарское"     --label "Прорыв плотины"
```
python scripts/prepare.py --clean    # сборка ассетов в web/data/

cd web && python -m http.server 8000
```

Открыть <http://localhost:8000>. Пробел — пуск/пауза, стрелки на шкале
времени — по кадру, перетаскивание гидрографа — перемотка.

> Открывать `index.html` двойным кликом нельзя: `fetch` манифеста
> заблокирует CORS. Нужен любой локальный сервер.


## Что считается по дороге

Помимо кадров `prepare.py` кладёт в `web/data/`:

- `*_maxdepth.png` — огибающая максимальных глубин за весь период.
  Показывается кнопкой «Максимум».
- `*_arrival.png` — **время добегания**: индекс кадра, в котором пиксель
  залился впервые. В интерфейсе пока не используется, но посчитан и лежит
  в манифесте — это готовый третий слой, если карта пойдёт в реальную
  работу по ЧС.
- гидрограф площади затопления, средней и максимальной глубины по кадрам —
  это он рисуется в нижней полосе.

Площадь приводится к реальной: Меркатор растягивает её в `1/cos²φ`, на
широте 55° это ровно в три раза.

## Публикация

Ассеты (`web/data/`) коммитятся, исходные растры — нет: `data/` в
`.gitignore`. Пуш в `main` запускает workflow, который выкладывает `web/`
на Pages. В настройках репозитория нужно один раз выставить
**Settings → Pages → Source → GitHub Actions**.

## Структура

```
scripts/prepare.py         пайплайн: GeoTIFF → WebP-атласы + manifest.json
scripts/import_rasmapper_tiles.py  тайловый кэш .db → GeoTIFF
web/index.html             разметка
web/style.css              палитра и типографика
web/app.js                 распаковка, рендер, гидрограф, шкала
web/data/                  собранные ассеты (коммитятся)
```
